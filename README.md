# Hambourg — installation automatique via GitHub Pages

## 1. Créer le dépôt
Crée un nouveau dépôt GitHub public nommé `hambourg`.

## 2. Envoyer les fichiers
Dépose **tout le contenu de ce dossier**, y compris le dossier `.github`.

## 3. Activer GitHub Pages
Dans le dépôt :
**Settings → Pages → Source → GitHub Actions**

Le site sera ensuite publié automatiquement à chaque modification.

## 4. Installer sur iPhone
Ouvre :
`https://TON-IDENTIFIANT.github.io/hambourg/install.html`

Puis :
**Partager → Sur l’écran d’accueil → Ajouter**

Apple impose cette confirmation finale : aucune PWA ne peut s’installer automatiquement sur iPhone sans action de l’utilisateur.
