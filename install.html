INSTALLATION IPHONE

Hambourg

Le guide est une application web installable. Sur iPhone, Apple demande une validation manuelle pour l’ajouter à l’écran d’accueil.

1. Ouvre le guide dans Safari

Utilise le bouton ci-dessous.

Ouvrir le guide
2. Appuie sur Partager

Le bouton carré avec une flèche vers le haut.

3. Choisis “Sur l’écran d’accueil”

Puis valide avec “Ajouter”. L’icône Hambourg apparaîtra comme une application.

Après installation, ouvre l’app depuis l’écran d’accueil plutôt que depuis Safari.
